# Software Defined Radio Based Wireless Communication using ADALM-Pluto SDR

This project focuses on implementing and analyzing a QPSK-based wireless communication system using the ADALM-Pluto Software Defined Radio (SDR) and Python. The objective was to gain practical experience in digital communication, SDR-based signal transmission and reception, and real-world signal processing.

A QPSK transmitter and receiver chain was implemented to transmit and recover digitally modulated data through a wireless channel. The received complex baseband signal was analyzed in the In-phase (I) and Quadrature (Q) domains to understand the behavior of the received signal under practical channel and noise conditions.

Signal analysis techniques were used to visualize the received QPSK constellation and examine the signal's frequency-domain characteristics through Power Spectral Density (PSD) analysis. Frequency synchronization and timing synchronization techniques were implemented to compensate for frequency and timing errors and improve reliable symbol recovery at the receiver.

The project provided hands-on experience with SDR hardware, QPSK modulation, complex IQ signals, synchronization, constellation analysis, and practical wireless communication system implementation.

### Tools Used

* ADALM-Pluto SDR
* Python
* QPSK Modulation
* IQ Signal Processing
* Power Spectral Density Analysis
* Frequency and Timing Synchronization

### Key Learning

* Practical implementation of a digital communication system
* QPSK transmission and reception
* IQ signal analysis
* Frequency and timing synchronization
* Constellation and PSD analysis
* Working with real SDR hardware
